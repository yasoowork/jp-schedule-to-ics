# JP Schedule to ICS

Convert Japanese schedule text into iCalendar (.ics) files.

## Features

- Parse Japanese schedule text
- Generate ICS calendar files
- Mobile friendly
- Works entirely in browser
- No server required

## Demo

https://schedule.yasoo.work

## Example Input

```text
■5/2（土）
17:00〜18:00
キックボクシング
```

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
